# Contributing

This public repository accepts focused fixes to documentation, public installers, wrappers, and verification tooling.

It does not accept Control-plane, marketplace, database, settlement, administrator, deployment, or proprietary Provider-agent source. Do not submit invitations, credentials, private endpoints, production configuration, proof artifacts, customer data, or private repository history.

Before opening a pull request:

1. Keep the change within the public surface described in [README.md](README.md).
2. Run the documented validation for changed scripts and links.
3. Use synthetic examples and absolute placeholder paths.
4. Confirm that no secret or internal address is present in the complete commit range.

Use GitHub private vulnerability reporting instead of a pull request or issue for security-sensitive findings.
