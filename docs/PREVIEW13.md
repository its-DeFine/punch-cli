# Preview.13 Provider serve packaging correction

`v0.1.0-preview.13` is installable only from the non-draft GitHub prerelease
when its Linux/x64 archive matches the accompanying `SHA256SUMS` asset.

Preview.13 makes one runtime correction to Preview.12: the bundled Provider
entrypoint installs Node's ESM `createRequire` bridge before loading the
CommonJS `ws` dependency. This prevents `punch-provider serve` from terminating
with `Dynamic require of "events" is not supported`.

The release gate builds the real Provider bundle and proves that `serve` enters
its resident polling state without that crash. Exact archive acceptance then
installs and runs the shipped Linux/x64 bytes with bundled Node.js 22.23.1.

All Preview.12 behavior and boundaries remain unchanged:

- continuous state-aware Buyer and Provider `punch` homes;
- preserved direct non-interactive commands;
- invitation-only supervised operation;
- owner-targeted `$0` offers only;
- contract-scoped NetBird gateway access;
- no payment, payout, settlement, refund, public free offer, or self-service
  Provider onboarding.

Preview.12 must not be used to run a Provider agent because its immutable
archive contains the packaging defect above. Existing Preview.12 identities,
credentials, setup state, and offers are not regenerated by installing
Preview.13. The Provider resumes with the same state directory and agent
configuration after checksum verification and installation.

The machine-readable [Preview.13 runtime contract](preview13-runtime-contract.json)
binds the exact private source and unchanged pilot policy.
